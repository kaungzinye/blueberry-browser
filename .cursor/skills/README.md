# Project skills

This directory vendors Cursor-compatible project skills from [mattpocock/skills](https://github.com/mattpocock/skills).

Upstream commit: `0288510dd61ff6ef7c2003834082ab8f2387e80e`

The upstream repository groups skills by category. They are flattened here as `.cursor/skills/<skill-name>/SKILL.md` so Cursor Cloud Agents can discover them as project skills.

Run or reference the `setup-matt-pocock-skills` skill first if you want to configure repo-specific domain, issue tracker, and triage context used by the engineering skills.
